# Hacker News views for Localnet

How a list of results and a page look in Localnet, a browser extension that is a personal search engine, after Hacker
News: numbered rows, each with its site, points, author, age and comments; and in Read, Verdana on
beige with each comment's head small and grey and its replies set in under it. Listed by the view source Localnet
starts with, [localnet-views](https://github.com/opowell/localnet-views), whose README says how a view is written.

- `source.json`: the views, and their files.
- `listing.html`, `listing.css`: the listing view, offered in Show as.
- `content.html`, `content.css`: the content view, Read's Look: its head over the page, and the page restyled.
